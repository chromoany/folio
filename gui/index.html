Folio · Markdown → 书式 PDF

生成带目录、真实页码、可点击跳转的 PDF；目录里能查到每一节的页码

① 选择 Markdown 文件（可多选，顺序即章节顺序）

把 .md 文件拖到这里，或点击选择

② 选项

只改版式口味。切换时会把该方案的一套默认值填进「详细」档的各项（字体、行距、字号、标题样式），填完仍可逐个改回来。
一套含正文 + 代码块 + 各级标题的字号（三档取自 ctexart 的中文字号体系）；切换时同样会填进「详细」档的字号框。
字体
四档字族分类同 LaTeX：中文（CJKmainfont）/ 西文（mainfont）/ 等宽（ttfamily）/ 等宽中文（等宽族里的汉字）。列表取本机 typst 能用的字体，未安装的会标注并在转换日志里提示；任意字族名可用命令行 --font-cjk / --font-latin / --font-mono 或配置 font.cjk / font.latin / font.mono / font.monoCjk。
字号与行距
影响 PDF 正文行距与各级标题上下的间距；任意值可用命令行 --leading（如 1.1em）。
页面
标题样式
默认即原有的书版式（左对齐 + 下划线 + 中文用字族自带的粗体）；ctexart 方案给的是居中 + 无下划线 + 黑体楷体。
mermaid 图
只影响文档里 mermaid 图的配色与连线走向；mermaid 图只在桌面版渲染进 PDF，命令行模式保留为代码块。
默认不抓取：远程图片以占位文字排版，转换完全离线、不受网络影响。

设置
即时生效。「跟随系统」随 Windows 的深色/浅色设置自动切换；主题只改变软件界面，不影响生成的 PDF。
仅桌面版生效：点窗口右上角「×」时按此处理；最小化仍进任务栏。
语言即时生效，托盘菜单与系统弹窗同步切换。
